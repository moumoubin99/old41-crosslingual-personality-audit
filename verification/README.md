On 2026-10-10, 23 CPU analysis outputs were regenerated from saved scores, numeric third-party metadata and the sanitized author-generated transcript copies. In 141384 common statistical numeric fields, all values agreed with the saved result JSONs within absolute and relative tolerance 1e-8. The checked outputs include four B0 score summaries, the B0 gate-readiness readout, the English inventory, the Chinese competence screen, the B3 indicators, four pole cells, the 2x2 contrasts/audit/robustness, length and surface diagnostics, the public-label concordance, three supplementary summary families, and Gemma pole-script counts.

`numeric_comparison.json` lists every output and its comparison count. Metadata fields and provenance hashes are excluded from the statistical comparison. The original English pole summary uses schema 1; the current reducer uses schema 2 and adds 75 numeric fields, including missingness, denominator, row-schema and item-parse diagnostics. This is a schema extension, not a change to common estimates. Archived saved summaries were not overwritten.

`publication_checks.json` records the verification scope and zero findings from a recursive scan of parsed JSON/JSONL strings plus source/document text for credential patterns, absolute machine paths, email addresses and IPv4 addresses. Interpreter caches and temporary replay outputs are excluded from the publication snapshot. The mask operation replaced 260 email occurrences in 114 files with non-contact strings of the same Unicode length. No original third-party dialogue `units-*.jsonl` was included.

The original scripts' built-in synthetic arithmetic checks passed. These are checks of the reducer, not a validation of any personality construct or rater. Statistical replay from saved data does not establish exact GPU inference re-execution. The unmatched source digest belongs only to the 100-row historical smoke2 test and is not read by the reported production reducers. No model/API was called for these checks. The platform tested was Linux/WSL with Python 3.13.
